# SEED — 학업실수 기반 자기주도학습 프로그램

국립목포대학교 **교수학습이러닝센터**의 학습법 프로그램이자, **교육학과** 박사학위논문 연구로 함께 진행되는 **참여자 전용 웹 애플리케이션**입니다.

접속하려면 연구 참여자에게 개별 발급된 학번과 접속코드가 필요합니다.

## 이 저장소에 없는 것

프로그램의 교육 내용(활동 문항·카드·자료)과 참여자가 남긴 기록은 이 저장소에 포함되어 있지 않습니다. 모두 접근이 통제된 별도의 데이터베이스에 보관됩니다.

## 이용 조건

본 저장소의 모든 내용에 대해 무단 복제·배포·2차 저작을 금하며, 기계학습을 포함한 자동 수집·학습 목적의 이용을 허용하지 않습니다. (`robots.txt` 참조)
